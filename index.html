Data Engineering & Feature Pipeline Architecture

Detailed documentation of our in-house data preprocessing, physics-based feature transformations, and ML inference pipeline.

Stage 1: Real-Time Sensor Ingestion (Digital Weather Station)

The Open-Meteo API functions purely as an automated environmental sensor. It streams raw temperature (°C), rainfall rate (mm/h), wind velocity (km/h), and volumetric soil moisture (0-7cm). The API performs zero machine learning and has no concept of mine operations or shortfall.

Stage 2: Temporal Resampling & Missing Value Imputation

Our Python/JS engine resamples hourly weather readings into 7-day rolling operational windows aligned with MOIL mine shift schedules. Missing sensor values are imputed using inverse-distance-weighted spatial interpolation from neighboring regional centroids.

Stage 3: Domain-Specific Feature Engineering

We formulate specialized mining engineering indicators:
• Soil Saturation & Pit Flooding Index (SFRI): Computes water accumulation probability based on rainfall and topsoil saturation.
• Haul Road Degradation Factor: Translates clay soil moisture into wheel slip, haul truck cycle slowdown, and mechanical transmission strain.
• DGMS Blasting Clearance Model: Checks lightning and wind criteria to enforce statutory explosive safety compliance.

Stage 4: Dual-Tree Ensemble Inference (RF vs XGBoost)

Engineered vectors are evaluated locally by our trained Random Forest (120 trees, MAE 26.12 t) and XGBoost (100 trees, MAE 25.02 t) models to generate the final shortfall gap and operational recommendations.
